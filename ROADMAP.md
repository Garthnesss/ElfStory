# ElfStory — Roadmap

Phases are gated on verification, not dates. A phase is done when STATUS.md
can state its claim with evidence behind it. Sequencing follows the
Nov 14, 2026 adversarial audit and Garth's picks from its decision pack.

## Phase 0 — "Ship-safe" (P0 fixes — Garth's pick, Nov 14, 2026)
- Close the 3 unbounded exploits: Vex's repeatable +15g tip, Runeforge value compounding on rune swaps, duplicate Whispering Bells in side dungeons (+ gated bell interaction in App).
- Confirmation on destructive actions: slot delete, New Adventure over an occupied slot, Play Again; remove Enter/Space auto-start on Title and auto-Play-Again on Game Over.
- Autosave: local save every 25 turns while playing + save on tab hide/close; persist mute and zoom preferences.
- ErrorBoundary around the app so a render crash shows a recoverable screen instead of a white page.
- Regression tests for the 3 exploits in `tests/engine.test.ts` style.
- Gate: `npm test` green including new regression tests, `tsc --noEmit` clean, `npm run build` clean, and each exploit's repro from the audit no longer works.

## Phase 1 — "Difficulty that scales" (P1 — DONE Nov 14, 2026; sim-verified, see STATUS.md and `tools/difficulty_sim.py`)
- Rebalance early game: enemy HP bases up ~2–3× and/or player ATK growth down, so floors 1–7 are fights, not one-shots.
- Scale story bosses to expected arrival level (Malakor especially; current: dies in 3–4 basic attacks); fix the inversion where side boss Kaelthar (359 HP / 57 ATK) massively out-stats the final boss.
- Scale Crimson Draught healing and companion HP/damage with level/depth (companion currently flat 24 HP, perma-dead from ~floor 5).
- Decide the intended Endless Abyss death curve and tune XP curve / enemy ATK growth to land there (currently: level stalls ~20, guaranteed death ~floor 25–40).
- Gate: simulation (audit's `difficulty_sim.py` method) shows TTK 2–5 on normal enemies per floor, bosses surviving a real rotation, and no boss inversion; plus a played full run by Garth.

## Phase 2 — "Top-end shell" (P2 — DONE Nov 14, 2026 for the five delivered features; see STATUS.md)

## Phase 4 — "Polish & hardening" (P4) — DONE Nov 14, 2026 (working tree; tests 69/69, tsc + build clean, sim extended)
Closes the remaining Phase 2 follow-ups (difficulty select, key rebinding, save version field + per-slot corruption isolation, ending credits, save-slot completion stamp). P1 tuning is untouched: the base constants remain the Standard tier.
- ✅ **Difficulty select** — three tiers (Story / Standard / Hardened) picked on the New Adventure flow and changeable mid-run in Settings. Multipliers (enemy HP / enemy ATK / XP): Story ×0.75 / ×0.85 / ×1.15, Standard ×1.0 across the board, Hardened ×1.25 / ×1.15 / ×1.10. HP/ATK scaling funnels through `scaleEnemyForDifficulty` inside `createEnemy`, so every spawn path (regular, story bosses, elites, side bosses via promote+tune, Abyss) is covered; the XP multiplier applies inside `grantXpAndCheckLevel`. Difficulty is per-run, stored in the save bundle (`difficulty` field; legacy saves default to Standard); a mid-run change applies to newly encountered enemies/floors — already-spawned enemies keep their stats. Current tier shows in the pause menu.
- ✅ **Save versioning + per-slot corruption isolation** — `SAVE_VERSION` (= 1) in `src/game/saveSlots.ts`, stamped into every bundle on every save path (manual, zone-transition, autosave). Missing version = legacy bundle, hydrates normally; a newer version is refused gracefully with a visible message; an unparseable/invalid slot renders as corrupted in the Title Screen list (delete still works) without breaking the list or other slots. Slot keys unchanged (`ashen_glyph_save_v2_slot_N`).
- ✅ **Key rebinding** — a keymap in the per-device settings blob (merged over defaults, so old blobs hydrate): all 14 single-key actions from the App keyboard handler (movement ×4, wait, interact, explore, rest, quick heal, skills, inventory, journal, map, guide). Settings UI: click a row, press a key; Escape cancels; binding onto a taken key swaps the two; Reset Defaults restores the factory map. Arrow keys always move and Enter always interacts (hardcoded fallbacks); number-row skills/runes, Tab and Escape stay fixed. The handler routes through the pure `resolveKeyAction` resolver.
- ✅ **Credits roll + completion stamp** — `CreditsScreen`: slow auto-scrolling credits, dismissed by any key/click, reachable from a Title Screen "Credits" button and from the Ending Screen. Completion stamp: reaching the ending records `completedAtMs` on the active save (first stamp wins, survives Abyss continuation and re-saves); the Title Screen slot list marks stamped slots "✦ Completed".
- Still open from the Phase 2 follow-up list (not this phase): text size / colourblind-safe signalling, contextual tutorial coach-marks at first telegraph/inscription/prodigy sighting.
